ImageResizer does far more than resize. With 40+ plugins, you can transform, enhance, filter, and compose images — all from a URL query string. Every example below is a live image processed by ImageResizer.

## Transform

### Scale with fit modes

Control how images fit their target dimensions.

| Mode | Result |
|------|--------|
| **max** (default) | Scales down to fit within the box, preserving aspect ratio |
| **pad** | Scales to fit, adding whitespace to fill remaining space |
| **crop** | Scales to fill the box, cropping excess |
| **stretch** | Distorts to fill exact dimensions |

![Fit max — proportional downscale](https://z.zr.io/ri/utah2.jpg?width=200&height=150&mode=max)
![Fit pad — padded to fill](https://z.zr.io/ri/utah2.jpg?width=200&height=150&mode=pad)
![Fit crop — filled and cropped](https://z.zr.io/ri/utah2.jpg?width=200&height=150&mode=crop)

## Advanced

### Face and eye detection

The **Faces** plugin uses OpenCV to detect faces and eyes. Use it to auto-crop portraits, apply red-eye correction, or build face-aware thumbnails.

### Red-eye repair (RedEye plugin)

Automatically detects and corrects red-eye in flash photography.

### Encoding and compression

- **JPEG** quality tuning — `quality=10` to `quality=100`
- **WebP** output via the WebP plugin
- **PNG** with 8-bit quantization via PrettyGifs

![Low quality JPEG](https://z.zr.io/ri/utah2.jpg?width=200&quality=10)
![High quality JPEG](https://z.zr.io/ri/utah2.jpg?width=200&quality=90)

### Overlays and watermarks

The **Watermark** plugin composites text or image overlays at configurable positions and opacity levels. Supports tiling, relative sizing, and per-image override.

### Upscaling

By default, ImageResizer only downscales. Set `scale=both` to allow upscaling when needed, or `scale=canvas` to upscale only the canvas.
