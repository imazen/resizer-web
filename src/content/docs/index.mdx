## Your server can do this 50,000x faster than you

<p class="lead">"Save for Web" is dead. Responsive sites serve different images to phones, tablets, laptops, retina displays, and slow connections. That's not two sizes — it's a matrix of widths, pixel densities, and formats. You can't maintain that matrix by hand.</p>

ImageResizer sits inside IIS, intercepts image requests, and generates what you need on the fly. You keep one source image; the URL determines the output.

<CardGrid stagger>
  <Card title="URL API" icon="pencil">
    Resize, crop, rotate, pad, watermark, and adjust images with query parameters. No code changes to your app — works with any `<img>` tag.
  </Card>
  <Card title="40+ plugins" icon="puzzle">
    Disk caching, S3/Azure storage, watermarking, face detection, white balance, seam carving, PDF rendering, and more. Enable what you need.
  </Card>
  <Card title="Drop-in install" icon="rocket">
    NuGet install into any ASP.NET app. Works alongside your existing CMS — DNN, Umbraco, Orchard, Sitefinity, and others.
  </Card>
  <Card title="Built for servers" icon="setting">
    Designed for multi-year uptimes. Managed disk cache, memory limits, DDOS-resistant request pipeline. Not a desktop library repurposed for the web.
  </Card>
</CardGrid>
